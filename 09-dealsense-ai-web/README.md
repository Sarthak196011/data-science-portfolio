# DealSense AI - Autonomous Price Intelligence Web Application

## Overview
DealSense AI is an autonomous, standalone web application that compares real-time prices across major retailers, benchmarks against official brand stores, visualizes Store Rating vs Total Cost via interactive scatter matrices, and fetches live verified product imagery via Wikipedia API.

## Running Locally
Simply double click `index.html` to open in any web browser, or serve via any HTTP server:
`ash
python -m http.server 8506
`
